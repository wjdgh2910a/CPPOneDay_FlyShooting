C++언어를 배우고 Unreal을 경험해보지 못한 학생을 대상으로 4시간 안에 언리얼을 활용한 게임개발의 방향성을 배울 수 있는 특강입니다.

이 특강을 통해 얻을 수 있는 지식

1.Unreal Engine의 C++ Class 구조와 특징

2.Unreal Engine의 Actor와 Component에 대한 기본기

3.Character와 Controller 그리고 GameModeBase의 관계와 활용방법

4.PlayerController에서 UEnhancedInputSystem를 활용한 입력구조 설계

5.USplineComponent를 활용한 설계된 이동과 Actor Spawn방법

6.Collision Component를 활용한 Actor간의 충돌 설계
